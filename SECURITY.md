# Security policy

Ferry handles SSH keys, passwords and cloud credentials, so security reports
are very welcome.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | yes       |
| < 0.3   | no        |

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/trevortomlin/ferry/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You should get a
reply within 72 hours. We will keep you updated, agree on a disclosure date with you,
and credit you in the advisory unless you'd rather stay anonymous.
