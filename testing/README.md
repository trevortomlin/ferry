# Test servers

An SFTP server and an S3-compatible server (MinIO) on localhost, so protocol
work and large-directory performance can be exercised without an AWS account or
a remote host.

```sh
./up.sh              # start both, generate a throwaway SSH keypair
./seed.sh 100000     # fill both with 100k entries
./down.sh --wipe     # stop and delete all data
```

Docker's daemon must be running: `sudo systemctl start docker`.

## Credentials

All throwaway, all bound to 127.0.0.1.

| | |
| --- | --- |
| SFTP | `ferry@127.0.0.1:2222`, password `ferry` |
| SFTP uid | 1000, matching the host user, so `/upload` is writable |
| SFTP key | `keys/id_ed25519` (gitignored, regenerated by `up.sh`) |
| S3 endpoint | `http://127.0.0.1:9000`, region `us-east-1` |
| S3 bucket | `ferry-test` |
| S3 keys | `ferryadmin` / `ferryadmin` |

To test SSH agent auth: `ssh-add testing/keys/id_ed25519`.

## What gets seeded

- `big/` — `COUNT` empty files, for scroll and listing performance.
- `mixed/` — a handful of files with different sizes and a subdirectory, for
  sorting and column rendering.

100k entries takes a while to push into MinIO; 1000 is the sane default for
everyday work.
